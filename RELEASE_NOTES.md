
# PDF Assignment Marker — Release Notes

## Version 11.1.2 — Enhanced Text Formatting and Multilingual Support

This release provides greater flexibility in text formatting, font management and multilingual PDF annotation.

### New Features and Improvements

- Expanded font size range from 5 to 36 px for Text, Part Marks and Total Marks.
- Font selection from installed Windows system fonts.
- Language-specific font preference remembrance.
- Automatic remembrance of font size and colour preferences.
- Live font, size and colour adjustment without closing the active text box.
- Automatic cursor positioning when switching between LTR and RTL languages.
- Resizable text boxes with automatic text wrapping.
- Automatic display of the selected annotation's font and font size.
- Consistent text formatting across both panes in Split View.
- Corrected duplicate text and outline rendering during text box editing.
- Updated built-in Help and About information.

### Preserved Features

All existing annotation tools, default settings, automatic marks calculations, PDF saving and folder preferences remain available.

## Version 11.1.1 — Text Selection, Copy Tool and Keyboard Shortcuts

This release improves marking efficiency and interaction with PDF documents.

### New Features and Improvements

- Dedicated text selection and copying tool.
- Copy text from supported PDF documents to other applications.
- Keyboard shortcuts for selected annotation tools and menu commands.
- Improved accessibility and marking workflow.

## Version 11.1.0 — Interface and Annotation Improvements

This release introduces a more professional interface and additional annotation features.

### New Features and Improvements

- Redesigned application header.
- Improved floating toolbox.
- Additional annotation symbols: Exclamation Mark, Question Mark and Golden Star.
- Improved page navigation controls.
- Improved colour selection and opacity controls.
- Improved Full Window, Half-Screen and Split View layouts.
- Updated Help and About information.

## Version 11.0.2 — Compact Interface Update

This release introduces a more compact and professional interface, providing more space for viewing and marking PDF documents.

### Improvements

- Professional Light Blue title bar.
- Compact horizontal and vertical toolbars.
- Larger document viewing area, especially on laptops.
- Improved page navigation and clickable document filenames.
- Improved Single View and Split View document fitting and centring.
- Improved selection, scrolling and keyboard navigation.
- Improved document rendering and view switching.
- Updated About and Help information.

## Version 11.0.1 — Maintenance Update

This maintenance release improves PDF viewing, zooming and scrolling reliability while preserving the existing interface and marking features.

### Corrections

- Equal document panel widths: Fixed an issue where opening certain large PDF books caused the two document panels to become unequal.
- Rapid zoom rendering: Corrected temporary duplicated or blank pages during rapid zooming.
- Horizontal scrolling: Corrected the horizontal scrollbar so users can navigate enlarged PDF pages.
- Scrollbar after rotation: Corrected scrollbar adjustment when a PDF page is rotated between portrait and landscape orientations.

### Unchanged Features

All existing annotation tools, English and Dhivehi text entry, part marks, automatic totals, PDF saving, Single View, Split View and page navigation are retained.

This release introduces no new features.

## Version 11.0.0 — First Public Release

The initial public release of PDF Assignment Marker, a free and open-source Windows application for reading, annotating, marking and saving PDF documents.
