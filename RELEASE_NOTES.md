# PDF Assignment Marker — Release Notes

## Version 11.0.1 — Maintenance Update

This maintenance release improves PDF viewing, zooming, and scrolling reliability while preserving the existing interface and marking features.

Corrections

- Equal document panel widths: Fixed an issue where opening certain large PDF books caused the two document panels to become unequal.

- Rapid zoom rendering: Corrected temporary duplicated or blank pages during rapid zooming.

- Horizontal scrolling: Corrected the horizontal scrollbar so users can navigate enlarged PDF pages.

- Scrollbar after rotation: Corrected scrollbar adjustment when a PDF page is rotated between portrait and landscape orientations.

## Unchanged Features

All existing annotation tools, English and Dhivehi text entry, part marks, automatic totals, PDF saving, Single View, Split View, and page navigation are retained.

This release introduces no new features.

## Version 11.0.0 — First Public Release

The initial public release of PDF Assignment Marker, a free and open-source Windows application for reading, annotating, marking, and saving PDF documents.
